# Шаг 5. README проекта

Проект уже содержит исходный код, конфигурацию
и документацию.

Но человеку, который впервые откроет репозиторий,
пока трудно понять, что это за проект и как он устроен.

Ваша задача — создать качественный `README.md`.

## 1. Разберитесь с проектом

Перед написанием README внимательно изучите
содержимое репозитория.

Обратите внимание на:

- исходный код в каталоге `src`;
- файлы в каталоге `docs`;
- пример конфигурации `env_example`;
- структуру проекта в целом.

По этим файлам самостоятельно определите назначение
проекта и используемые в нём технологии.

## 2. Создайте README.md

Создайте в корне репозитория файл:

`README.md`

README должен содержать:

### Название проекта

Придумайте короткое название, соответствующее
содержимому проекта.

### Описание

Кратко объясните:

- для чего предназначен проект;
- что делает программа;
- какие технологии или компоненты используются.

Необходимую информацию найдите самостоятельно
в файлах репозитория.

### Структура репозитория

Покажите структуру проекта и укажите реальные
файлы вашего варианта задания.

Например:

    project/
    ├── src/
    │   └── ...
    ├── docs/
    │   └── ...
    ├── env_example
    └── README.md

### Запуск

Добавьте краткую инструкцию, объясняющую,
как запустить программу из каталога `src`.

### Конфигурация

Объясните назначение `env_example` и как на его
основе подготовить локальную конфигурацию приложения.

Не переносите значения секретов из истории
репозитория в README.

## 3. Проверьте результат

Представьте, что репозиторий впервые открыл
другой разработчик.

Из README он должен суметь понять:

- что это за проект;
- какие технологии используются;
- из каких основных файлов и каталогов он состоит;
- как запустить программу;
- как подготовить конфигурацию.

## 4. Сохраните изменения

Создайте коммит с кратким, но понятным описанием
выполненной работы и отправьте изменения.

> 💡 **Не появился следующий этап?**
> Откройте раздел **CI/CD** и посмотрите результат
> последней проверки.
> Там будет указано, что необходимо исправить.
