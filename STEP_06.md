# Шаг 6. Итоговая проверка

Основная часть задания завершена.

Теперь необходимо запустить итоговую автоматическую
проверку всего репозитория и истории Git.

## 1. Запустите итоговую проверку

1. Убедитесь, что все изменения сохранены
   в коммитах и отправлены в GitVerse.
2. Откройте раздел **CI/CD** репозитория.
3. Найдите workflow **Git Quest — итоговая проверка**.
4. Запустите его вручную для вашей рабочей ветки.
5. Дождитесь завершения проверки и изучите результат.

Итоговая проверка проверяет не только файлы проекта,
но и историю вашей работы с Git.

В рабочей ветке должно быть:

- не менее **8 ваших собственных коммитов**;
- среди них не менее **3 коммитов с осмысленными
  сообщениями**.

Стандартные сообщения GitVerse вроде `Create: ...`,
`Update: ...` и `Delete: ...` учитываются в общем
количестве коммитов, но не считаются осмысленными
сообщениями.

Коммиты **Git Quest Bot** не учитываются.

Если содержательных сообщений пока меньше трёх,
**не нужно переписывать старые коммиты**.
Продолжайте работу обычным способом и используйте
понятные описания в следующих коммитах.

Если итоговая проверка обнаружит другую проблему,
исправьте её, создайте новый коммит, отправьте изменения
и снова запустите итоговый workflow вручную.

## 2. Создайте Pull Request

Когда workflow **Git Quest — итоговая проверка**
завершится успешно, создайте **Pull Request**
из вашей рабочей ветки в ветку `master`.

Pull Request — последнее действие этого задания.

После его создания работа считается отправленной
на проверку преподавателю.
