# Шаг 4. Структура проекта

Репозиторий начинает превращаться в настоящий проект.

Теперь необходимо правильно организовать его файлы.

## 1. Исходный код

Создайте файл:

`src/temp_cleaner.py`

Задание для этого файла:

**небольшая программа, связанная с временными файлами. Программа должна запускаться без ошибки.**

Файл должен:

- быть написан на Python;
- содержать осмысленный код;
- быть непустым;
- запускаться без ошибки.

Сложную программу писать не требуется.


## 2. Документация

Создайте файл:

`docs/vibe_app.pdf`

Задание:

**небольшой документ о приложении, использующем Gemini, базу данных и Supabase.**

Содержание этого файла будет проверено
преподавателем отдельно.

Автоматическая проверка проверит только наличие
документа и то, что файл не пустой.


## 3. Сохраните изменения

В результате в репозитории должны появиться
каталоги:

`src`

и:

`docs`

Создайте коммит с кратким, но понятным описанием
выполненной работы и отправьте изменения.


> 💡 **Не появился следующий этап?**
> Откройте раздел **CI/CD** и посмотрите результат
> последней проверки.
> Там будет указано, что необходимо исправить.
