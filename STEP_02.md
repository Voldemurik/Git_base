# Шаг 2. Файл .gitignore

В проектах часто существуют файлы и каталоги,
которые не должны попадать в репозиторий.

Для этого Git использует специальный файл
`.gitignore`.

## Ваше задание

Создайте в корне репозитория файл:

`.gitignore`

Добавьте в него следующие правила:

- `.vscode/`
- `*.tmp`
- `build/`

После этого сохраните изменения, создайте коммит
с понятным описанием и отправьте изменения.

Не изменяйте:

- `STEP_02.md`
- `.quest/variant`

> 💡 **Не появился следующий этап?**
> Откройте раздел **CI/CD** и посмотрите результат
> последней проверки.
> Там будет указано, что необходимо исправить.
