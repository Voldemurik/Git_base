# Шаг 3. Кажется, кто-то закоммитил секреты 😱

Вы подключились к проекту после другого разработчика.

В репозитории оказался файл `.env` с настройками,
похожими на API-ключи и другие секреты.

**Все значения в задании вымышленные.**

## Ваша задача

### 1. Создайте `env_example`

Скопируйте туда все имена переменных из `.env`,
но удалите их значения.

Например:

    OPENAI_API_KEY=secret

должно стать:

    OPENAI_API_KEY=

### 2. Удалите `.env`

Файл `.env` не должен остаться в проекте.

### 3. Добавьте `.env` в `.gitignore`

Добавьте правило:

`.env`

### 4. Сохраните изменения

Создайте коммит с понятным описанием
и отправьте изменения.

> 💡 **Не появился следующий этап?**
> Откройте раздел **CI/CD** и посмотрите результат
> последней проверки.
> Там будет указано, что необходимо исправить.
