# Vibe App — учебный проект (Gemini + Supabase)

## Описание

Учебный проект демонстрирует, как устроено приложение на базе Gemini
(ИИ-модель от Google) и Supabase (облачный бэкенд с базой данных
PostgreSQL), и как правильно организовать репозиторий такого приложения:
исходный код, документацию и конфигурацию.

Программа `src/temp_cleaner.py` написана на Python и работает с временными
файлами: находит временные файлы (`*.tmp`) в рабочем каталоге, показывает
их список и удаляет ненужные, освобождая место. Запускается без ошибок и
не требует внешних зависимостей.

В каталоге `docs` лежит документ `docs/vibe_app.pdf` — краткое описание
приложения, которое использует Gemini для генерации ответов и Supabase
(database) для хранения пользователей и истории запросов.

Используемые технологии и компоненты:

- **Python 3** — язык, на котором написан `temp_cleaner.py`;
- **Gemini API** — программный доступ к ИИ-модели Google;
- **Supabase** — готовый бэкенд: база данных PostgreSQL, авторизация, хранилище;
- **PostgreSQL** (`DATABASE_URL`) — реляционная база данных;
- **Git / GitVerse CI** — контроль версий и автоматическая проверка заданий;
- **env_example** — шаблон переменных окружения (ключи и настройки).

## Запуск

Требуется Python 3.8 или новее. Из корня репозитория:

```bash
python3 src/temp_cleaner.py
```

В Windows команда обычно выглядит так:

```bash
python src\temp_cleaner.py
```

Программа выведет список найденных временных файлов и результат очистки.
Внешние библиотеки устанавливать не нужно.

## Конфигурация

Файл `env_example` — это шаблон конфигурации. Он хранится в репозитории и
показывает, какие переменные окружения нужны приложению, но содержит только
демонстрационные значения-заглушки, а не настоящие ключи.

Чтобы подготовить локальную конфигурацию, скопируйте шаблон в файл `.env`
и подставьте свои значения:

```bash
cp env_example .env
```

Назначение переменных:

| Переменная            | Назначение                                        |
|-----------------------|---------------------------------------------------|
| `GEMINI_API_KEY`      | ключ доступа к Gemini API                          |
| `CURSOR_AGENT_TOKEN`  | токен для агента в редакторе Cursor                |
| `DATABASE_URL`        | строка подключения к базе данных PostgreSQL        |
| `SUPABASE_KEY`        | ключ доступа к проекту Supabase                    |
| `DEBUG_MODE`          | режим отладки (`true` / `false`)                   |

Файл `.env` с реальными ключами добавляется в `.gitignore` и **никогда**
не коммитится. Секреты, которые когда-либо попадали в историю репозитория,
считаются скомпрометированными — их нужно перевыпустить, а не переносить
в README.
