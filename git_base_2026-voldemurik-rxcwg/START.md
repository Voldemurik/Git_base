# Git Quest — начало

Добро пожаловать в небольшое практическое задание по Git.

В этом задании инструкции будут появляться постепенно. Выполняйте каждый этап по порядку — после успешного выполнения текущего шага вы получите следующий.

## Шаг 1. Создайте рабочую ветку

В Git основная ветка проекта обычно называется `main`, а в GitVerse старое наследие - `master`.

Работать непосредственно в `main`\  `master` — плохая привычка. 
Изменения принято выполнять в отдельных ветках, а затем объединять с основной веткой после проверки.

### Ваше задание

1. Создайте **новую ветку** от ветки `master`.
2. Название ветки придумайте самостоятельно.
3. Переключитесь на созданную ветку.
4. Все последующие задания выполняйте **только в ней**.

После создания ветки GitVerse автоматически обнаружит её и запустит проверку.

> **Важно:** не удаляйте созданную ветку и не объединяйте её с `master`, пока задание не будет завершено.

### Небольшая подсказка

В интерфейсе Git-клиента найдите раздел управления ветками (**Branches / Ветки**).

Вам понадобится действие **создания новой ветки от `master`**.

Конкретные кнопки могут немного отличаться в зависимости от используемого Git-клиента/языка.

## Если что-то пошло не так

После отправки изменений GitVerse автоматически запускает проверку.

Если следующий этап задания не появился или вы считаете, что выполнили
всё правильно, откройте раздел **CI/CD** вашего репозитория и посмотрите
результат последнего запуска.

В журнале проверки будет указано:

- какой этап сейчас проверяется;
- что было найдено в репозитории;
- что выполнено правильно;
- что необходимо исправить.

После исправления ошибки создайте новый коммит и снова отправьте изменения.
Проверка запустится автоматически.
